# 🕯 فرزندان ایران

یادبودی تعاملی برای ثبت و زنده‌نگه‌داشتن نام جانباختگان **۱۸ و ۱۹ دی ۱۴۰۴**.

نقشه‌ی تعاملی ایران با نماهای **سه‌بعدی** و **دوبعدی**؛ با کلیک روی هر استان، فهرست نام‌ها و جزئیات هر نفر نمایش داده می‌شود.

---

## ✨ امکانات

- 🗺 **نقشه‌ی سه‌بعدی واقعی** (WebGL / Three.js): چرخش، بزرگ‌نمایی، برجسته‌شدن سه‌بعدی استان‌ها و چرخش آرام خودکار
- 🗺 **نمای دوبعدی** (SVG) برای دستگاه‌های ضعیف‌تر
- ✨ ذرات نور شناور روی استان‌هایی که نام دارند
- 🔍 **جست‌وجو** بر اساس نام، شهر یا استان
- 🌙 حال‌وهوای شبِ سوگوار: نورپردازی سرد، مهِ آرام و تنها یک شمعِ یادبود
- 📱 کاملاً واکنش‌گرا (موبایل و دسکتاپ)
- 📦 **بدون هیچ وابستگی به CDN خارجی** — همه‌ی کتابخانه‌ها و فونت‌ها محلی هستند، پس در ایران هم بدون تحریم باز می‌شود

## 📁 ساختار پروژه

```
farzand-iran/
├── index.html            ← صفحه‌ی اصلی
├── css/style.css         ← استایل‌ها
├── js/
│   ├── app.js            ← هسته: پنل، نقشه‌ی دوبعدی، جست‌وجو، شمع
│   └── map3d.js          ← نقشه‌ی سه‌بعدی (Three.js)
├── data/
│   ├── victims.js        ← ⭐ نام‌ها را اینجا اضافه کنید
│   └── iranMap.js        ← هندسه‌ی نقشه‌ی استان‌ها (خودکار تولید شده)
├── vendor/               ← three.js و لودر SVG (محلی)
└── assets/fonts/         ← فونت وزیرمتن (محلی)
```

## ➕ چگونه نام اضافه کنیم؟

فایل `data/victims.js` را باز کنید. هر نام یک آبجکت در آرایه‌ی `victims` است:

```js
{
  id: "v022",                 // شناسه‌ی یکتا (تکراری نباشد)
  name: "نام خانوادگی نام",    // نام کامل
  age: 24,                    // سن؛ اگر نامشخص بود null
  gender: "f",                // "f" زن | "m" مرد | "o" دیگر
  provinceId: "IR-07",        // کد استان (جدول زیر)
  city: "تهران – خانی‌آباد",  // شهر / محله
  dateFa: "۱۴۰۴/۱۰/۱۹",        // تاریخ شمسی (اختیاری)
  dateEn: "2026-01-09",       // تاریخ میلادی (اختیاری)
  note: "یک جمله درباره‌ی او", // شرح کوتاه
  source: "بی‌بی‌سی فارسی"     // منبع مستند
}
```

## ▶️ اجرای محلی

چون پروژه از `file://` کامل کار نمی‌کند، یک سرور محلی ساده:

```bash
cd farzand-iran
python3 -m http.server 8080
```

سپس در مرورگر: `http://localhost:8080`

## 🚀 دیپلوی

هیچ مرحله‌ی build ندارد؛ فقط فایل‌های استاتیک را منتشر کنید:

- **GitHub Pages:** در تنظیمات ریپو، `Settings → Pages → Branch: main → / (root)` را انتخاب کنید.
- **Netlify / Vercel / Cloudflare Pages:** کافی است پوشه‌ی پروژه را آپلود کنید (بدون تنظیمات خاص).

## 🔐 نکته‌ی امنیتی (Deploy Key)

دسترسی دستیار به این ریپو از طریق یک **Deploy Key** انجام می‌شود که فقط روی همین یک ریپو کار می‌کند. برای قطع کامل دسترسی، کافی است آن را از `Settings → Deploy keys` حذف کنید.

## 📝 منابع اولیه

فهرست کنونی «نمونه‌ی اولیه» از نام‌هایی است که در منابع مستند منتشر شده‌اند. برای تکمیل فهرست، منابع معتبر را در فیلد `source` هر نام ذکر کنید.
