# 🕯 فرزندان ایران

یادبودی تعاملی برای ثبت و زنده‌نگه‌داشتن نام جانباختگان **۱۸ و ۱۹ دی ۱۴۰۴**.

نقشه‌ی تعاملی ایران؛ با کلیک روی هر استان، پنجره‌ای با فهرست نام‌ها باز می‌شود و با کلیک روی هر نام، جزئیات آن نمایش داده می‌شود.

---

## ✨ امکانات

- 🗺 **نقشه‌ی تعاملی استان‌های ایران** (SVG) با برچسب تعداد نام‌ها روی هر استان
- 🪟 **پنجره‌ی استان**: با کلیک روی هر استان باز می‌شود و فهرست نام‌ها را نشان می‌دهد
- ⚡ **لیست مجازی (Virtualized)**: حتی با چند هزار نام در یک استان، فقط بخشِ قابل‌مشاهده رندر می‌شود و اسکرول کاملاً روان می‌ماند
- 🔍 **جست‌وجو** در کل سایت (نام، شهر، استان) + جست‌وجو داخل هر استان
- 🕊 **پنجره‌ی یادنامه**: با کلیک روی هر نام، جزئیات کامل (سن، شهر، تاریخ، شرح و منبع) نمایش داده می‌شود — با پشتیبانی از **عکس، ویدیو و صدا** برای هر نام
- 🔔 **صدای یادبود**: با کلیک روی هر نام، صدای یادبود پخش می‌شود. اگر برای آن فرد فایلِ صدای مراد ویسی (خواندن نامش) در فیلد `voice` ثبت شده باشد، همان پخش می‌شود؛ وگرنه ناقوسِ سوگوارِ ملایمی (Web Audio، بدون فایل) پخش می‌شود. دکمه‌ی 🔊/🔇 در هدر، صدا را خاموش/روشن می‌کند (وضعیت آن ذخیره می‌شود)
- 🌙 حال‌وهوای شبِ سوگوار: نورپردازی سرد، مهِ آرام و ذرات نورِ کم‌جان
- 📱 کاملاً واکنش‌گرا (موبایل و دسکتاپ)
- 📦 **بدون هیچ وابستگی به CDN خارجی** — فونت‌ها محلی هستند، پس در ایران هم بدون تحریم باز می‌شود

## 📁 ساختار پروژه

```
farzand-iran/
├── index.html            ← صفحه‌ی اصلی
├── css/style.css         ← استایل‌ها
├── js/app.js             ← کل منطق: نقشه، پنجره‌ها، لیست مجازی، جست‌وجو
├── data/
│   ├── victims.js        ← ⭐ نام‌ها را اینجا اضافه کنید
│   └── iranMap.js        ← هندسه‌ی نقشه‌ی استان‌ها (خودکار تولید شده)
└── assets/fonts/         ← فونت وزیرمتن (محلی)
```

## ➕ چگونه نام اضافه کنیم؟

فایل `data/victims.js` را باز کنید. هر نام یک آبجکت در آرایه‌ی `victims` است:

```js
{
  id: "v022",                 // شناسه‌ی یکتا (تکراری نباشد)
  name: "نام خانوادگی نام",    // نام کامل
  age: 24,                    // سن؛ اگر نامشخص بود null
  gender: "f",                // "f" زن | "m" مرد | "o" دیگر
  provinceId: "IR-07",        // کد استان (جدول زیر)
  city: "تهران – خانی‌آباد",  // شهر / محله
  dateFa: "۱۴۰۴/۱۰/۱۹",        // تاریخ شمسی (اختیاری)
  dateEn: "2026-01-09",       // تاریخ میلادی (اختیاری)
  note: "یک جمله درباره‌ی او", // شرح کوتاه
  source: "بی‌بی‌سی فارسی",   // منبع مستند
  born: "۱۹ اردیبهشت ۱۳۸۷",  // (اختیاری) تاریخ تولد
  lived: "نیشابور",           // (اختیاری) محل زندگی
  killedAt: "نیشابور – فرحبخش غربی", // (اختیاری) محل دقیق شهادت
  occupation: "دانش‌آموز رشته گرافیک", // (اختیاری) شغل/تحصیل
  photo: "https://.../a.jpg", // (اختیاری) عکس
  video: "https://.../a.mp4", // (اختیاری) ویدیو
  audio: "https://.../a.mp3", // (اختیاری) صدای داخل یادنامه
  voice: "assets/media/voice/x.mp3" // (اختیاری) صدای مراد ویسی هنگام خواندن نامش
}
```

فیلد `voice` مخصوص صدای مراد ویسی است که اسم فرد را می‌خواند («فرزند ایران و جان‌فدای میهن، جاویدنام …»). این فایل با کلیک روی اسم فرد به‌صورت خودکار پخش می‌شود. برای هر فرد باید فایل جداگانه باشد. نمونه‌ی آماده: `assets/media/voice/bahareh-shahmahri.mp3` (برای بهاره شاهمهری).

فیلدهای `born`، `lived`، `killedAt` و `occupation` در یادنامه به‌صورت جدول اطلاعات نمایش داده می‌شوند.

فیلدهای `photo`، `video` و `audio` اختیاری‌اند. اگر `video` باشد در پنجره‌ی یادنامه یک پخش‌کننده‌ی ویدیو، اگر `photo` باشد عکس، و اگر `audio` باشد پخش‌کننده‌ی صدا نمایش داده می‌شود (فایل صدا می‌تواند هم‌زمان با عکس هم باشد). فایل‌های محلی را در پوشه‌ی `assets/media/` بگذارید و آدرس نسبی بدهید (مثل `assets/media/bahareh-shahmahri.jpg`).

## ▶️ اجرای محلی

چون پروژه از `file://` کامل کار نمی‌کند، یک سرور محلی ساده:

```bash
cd farzand-iran
python3 -m http.server 8080
```

سپس در مرورگر: `http://localhost:8080`

## 🚀 دیپلوی

هیچ مرحله‌ی build ندارد؛ فقط فایل‌های استاتیک را منتشر کنید:

- **GitHub Pages:** در تنظیمات ریپو، `Settings → Pages → Branch: main → / (root)` را انتخاب کنید.
- **Netlify / Vercel / Cloudflare Pages:** کافی است پوشه‌ی پروژه را آپلود کنید (بدون تنظیمات خاص).

## 🔐 نکته‌ی امنیتی (Deploy Key)

دسترسی دستیار به این ریپو از طریق یک **Deploy Key** انجام می‌شود که فقط روی همین یک ریپو کار می‌کند. برای قطع کامل دسترسی، کافی است آن را از `Settings → Deploy keys` حذف کنید.

## 📝 منابع اولیه

فهرست کنونی «نمونه‌ی اولیه» از نام‌هایی است که در منابع مستند منتشر شده‌اند. برای تکمیل فهرست، منابع معتبر را در فیلد `source` هر نام ذکر کنید.
